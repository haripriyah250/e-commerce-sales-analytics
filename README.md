E-Commerce Sales Analytics

Project Overview

This project focuses on analyzing e-commerce sales data using Microsoft Excel to identify useful business insights and sales trends.

Tools Used

- Microsoft Excel

Skills Practiced

- Data Cleaning
- Removing Duplicate Records
- Handling Extra Spaces
- Pivot Tables
- Data Analysis
- Charts and Dashboard Creation

Project Tasks

- Cleaned the raw sales dataset.
- Identified and removed duplicate records.
- Analyzed sales by city.
- Analyzed sales by product category.
- Analyzed sales by payment method.
- Created Pivot Tables for summarizing sales data.
- Built an interactive-style sales dashboard using charts and summary metrics.

Project Outcome

Created an Excel dashboard to present sales insights in a clear and organized way.
